Training 1 – Understanding Attribute Weights

Rule: In every period, one of the attributes has a weight of 40 and is the most important attribute to determine the total value of the project. Since revealing an attribute has equal costs independent of its weight, always start with the attribute that has the highest weight as it gives you the most valuable information.

Example:

  • A1 = 40
  • A2 = 30
  • A3 = 20
  • A4 = 10
  • Knowing that reveal cost is the same for each attribute:
    • Revealing A1 gives information that accounts for two-fifths of the total score.
    • Revealing A3 accounts for only one-fifth of the total score.
    • Both cost 50 points, but A1 is far more valuable to reveal.

Exercise: You can reveal all attributes for free in the following exercise. Focus on finding out which attribute has an attribute weight of 40.

Training 2 – Inferring Attribute Connections

Rule: For each project, attribute values for A1 and A3 are always connected by a basic arithmetic operation (+, -, * or ÷). This operation remains the same for all rounds of a given period. So don’t pay twice for the same information for each project.

Example:

  • Imagine you reveal A1 for project 1 and see it is 9 in a round.
  • You then reveal A3 for the same project (Project 1) and see 3.
  • It could then be that A3 = A1 – 6 or A3 = A1 ÷ 3.
  • When you then reveal A1 and A3 for project 2 and you find 6 for A1 and 2 for A3, you know that the connection for this period is that A3 = A1 ÷ 3.
  • That means, from revealing A1, you can also infer the value of A3 (and vice versa). So, don’t pay twice for information you can infer from the rule.

Exercise: You can reveal all attributes for free in the following exercise. Focus on finding out the connection between attribute values A1 and A3.

Training 3 – Inferring Attribute Connections for A2

Rule: Between the five projects of a given round, attribute values for A2 are always connected by a basic arithmetic operation (+ or -). These operations remain the same for all rounds of a given period. So don’t pay twice for the same information for A2 of different options.

Example:

  • Imagine you reveal attribute A2 of all five projects and see the following:
    • A2 for Project 1 = 5
    • A2 for Project 2 = 2
    • A2 for Project 3 = 6
    • A2 for Project 4 = 9
    • A2 for Project 5 = 1
  • You then know that the rule for this period is:
    • A2 (Project 2) = A2 (Project 1) – 3
    • A2 (Project 3) = A2 (Project 2) + 4
    • A2 (Project 4) = A2 (Project 3) + 3
    • A2 (Project 5) = A2 (Project 4) - 8
  • Thus, for every round of a given period, you only need to reveal one A2 to infer the others. So don’t pay twice for information you can infer from the rule.

Exercise: You can reveal all attributes for free in the following exercise. Focus on finding out the connection between the A2 values of all five projects.

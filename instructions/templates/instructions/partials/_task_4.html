Employee's Task (4)


Reveal Cost

However, revealing Attribute Values is costly for employees. Specifically, every time an employee reveals an Attribute Value, the employee incurs additional costs of 50 points. That means, revealing more Attribute Values also leads to more Reveal Costs. Once an employee has revealed an Attribute Value, this can no longer be reversed.

Example (continued)

After revealing A2 of Project 3, an employee learns that this Attribute Value equals 3, resulting in an Expected Project Value (“EV Revealed”) of 90. The Expected Project Value per project will automatically update, taking into account the revealed Attribute Value.

Please note that the revealed Expected Project Value (EV Revealed) is calculated solely from the revealed Attribute Values. As we explained above, the more Attribute Values of a project are revealed, the closer this project’s EV Revealed will be to the Expected Project Value of this project.

Recall that the Realized Project Value is equal to the Expected Project Value (that is based on all four Attribute Values) plus a Noise Term.

The Reveal Cost also updates each time a new Attribute Value is revealed.



Employees can then reveal additional Attribute Values of the same or other projects. Every time, the corresponding Expected Project Value (EV Revealed) will be updated as well as the Reveal Cost.

Refresh Penalty

Please note: It is not allowed to refresh or reload the page at any point during the experiment. Refreshing the page will disrupt the experiment and data will not be recorded correctly. If an employee refreshes the page, they will receive a penalty for this round of 1000 points.

Please note that refreshing the page is more expensive than revealing all attribute values for all projects in a round. If you think that the program is stuck and does not move on, please raise your hand and someone will assist you.

Employee's Task (2)


Attribute Values and Weights

Both the Attribute Values and the Attribute Weights for all projects are unknown to employees at the beginning of every round. However, to determine which project offers the highest Expected Project Value, employees can choose to reveal the Attribute Values of A1, A2, A3 and A4 for each of the five projects.

The Attribute Weights (WeightA1 to WeightA4) are also unknown to employees. However, the following rules apply to the Attribute Weights:
  • All four Attribute Weights (WeightA1 to WeightA4) always add up to 100.
  • Every Attribute Weights is at minimum 10 and at maximum 40.
  • Every Attribute Weight will remain the same for all six rounds of every period.
  • The Attribute Weights will only change between periods. That means, for all six rounds of a new period, the Attribute Weights will have the same value. For the six rounds of a new period, the Attribute Weights will then take on new weights. However, all rules and the logic about the Attribute Weights we have just outlined will apply in all periods.
Employees can reveal Attribute Values (A1, A2, A3 and A4) for each project by clicking "Reveal" for any attribute of every project.

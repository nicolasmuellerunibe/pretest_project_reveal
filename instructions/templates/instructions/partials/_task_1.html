Employee's Task (1)


Every period consists of six rounds, as we will explain in more detail below.

In each round of each period, every employee performs a decision-making task individually.

The decision-making task will be the same in every round. It requires participants to choose one project from five project alternatives.

Every project has an Expected Project Value and a Realized Project Value.

As we will explain in more detail below, the value of a project is determined by four attributes (A1, A2, A3 and A4). Each attribute has an Attribute Weight representing the importance of this attribute. And each project has an Attribute Value for each attribute.



Expected Project Value

The Expected Project Value of every project is determined as follows:

Expected Project Value = WeightA1 * A1 + WeightA2 * A2 + WeightA3 * A3 + WeightA4 * A4

That means, the Expected Project Value of every project is determined by multiplying the Attribute Values (A1 to A4) with their respective Attribute Weights (WeightA1 to WeightA4).

Realized Project Value

However, like in practice, the Realized Project Value does not necessarily equal the Expected Project Value because uncertainty can affect the realized outcome of a project. Specifically, the Realized Project Value is equal to the Expected Project Value plus a Noise Term.

Realized Project Value = Expected Project Value + Noise Term

More information on the Noise Term will be provided later in the instructions.

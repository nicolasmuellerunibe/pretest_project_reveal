Employee's Task (3)


Revealing Attribute Values

Employees can choose to reveal Attribute Values for a project. Revealing Attribute Values for a project will allow employees to get a better idea of the Expected Project Value of a project.

Specifically, every time an employee reveals an Attribute Value for a project, the EV Revealed will be updated by this Attribute Value multiplied by its Attribute Weight (that means, contingent on which Attribute Value is revealed, the Expected Project Value is updated by either WeightA1 * A1 or WeightA2 * A2 or WeightA3 * A3 or WeightA4 * A4).

That means: The EV Revealed represents the part of the Expected Project Value that is already revealed. The more Attribute Values of a project are revealed, the closer the EV Revealed will be to the Expected Project Value of this project. For example, if all Attribute Values of a project are revealed, the EV Revealed would exactly equal the Expected Project Value.

Example

Imagine that an employee wants to reveal the Attribute Value A2 for Project 3. They can do so by clicking on “Reveal” for A2 of Project 3. Recall that “EV Revealed” captures the Expected Project Value based on the revealed Attribute Values so far.

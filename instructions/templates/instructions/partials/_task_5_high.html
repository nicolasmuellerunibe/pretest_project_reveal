Realized Project Value

After an employee has chosen a project, the Realized Project Value is determined. The Realized Project Value equals the total Expected Project Value plus a Noise Term that is randomly determined by the program.

Realized Project Value = Expected Project Value + Noise Term

As we explained above, like in the real world, the realized value of a project does not necessarily correspond to the Expected Project Value but is also influenced by uncertainty, because unexpected changes in the environment can increase or decrease the realized value of a project. This also means that even if all Attribute Values of a project are revealed and, thus the EV Revealed corresponds to the Expected Project Value, the Realized Project Value can still deviate.

The Noise Term varies between [-150; +150] points. That means, in every period, it can range between -150 and +150 points. The Noise Term is determined separately and randomly for every project and every period. That means, the noise term for a specific project in a specific period does not depend on the noise term for other projects or in earlier or later periods.

The Realized Project Value is important because it is a key determinant of an employee's performance in each round, as we will explain on the next screens.

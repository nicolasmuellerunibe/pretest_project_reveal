Then the Expected Project Value (EV Revealed) per project will automatically update, taking into account the revealed Attribute Value. Please note that the revealed Expected Project Value (EV Revealed) is calculated solely from the revealed Attribute Values.

In this example, the Attribute Value equals 4, resulting in an updated Expected Project Value of 200 points.

Recall that the Realized Project Value is calculated using all three Attribute Values, including those that are not revealed.

The Reveal Cost also updates each time a new Attribute Value is revealed.



Employees can then reveal additional Attribute Values of all projects. Every time, the Expected Project Value (EV Revealed) will be updated as well as the Reveal Cost.

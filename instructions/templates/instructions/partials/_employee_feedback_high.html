Employee Feedback


After an employee has made the project selection, they will receive immediate feedback on the following items:
  • The Realized Project Value: Recall that this is the Expected Project Value of the selected project if all Attribute Values had been revealed plus the Noise Term.
  • Recall that the Noise Term can be between [-150; +150] points.
  • The number of revealed Attribute Values.
  • The total Reveal Costs equal to the number of revealed Attribute Values multiplied with Reveal Cost of 50 points.
  • The Performance for this round equal to the Realized Project Value of the selected project less Total Reveal Costs and Training Revisit Costs.
